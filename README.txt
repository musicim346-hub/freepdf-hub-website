FREEPDF HUB REDESIGN — GITHUB PAGES

This is a redesigned static website package for freepdf.sbs.

PUBLISH:
1. Extract this ZIP.
2. Open your existing GitHub repository.
3. Upload all files and folders from inside the extracted folder to the repository root.
4. Keep index.html and CNAME in the root.
5. Commit changes. GitHub Pages should deploy from main / root.
6. Keep the custom domain freepdf.sbs configured in Settings > Pages.
7. Open https://freepdf.sbs after deployment completes.

INCLUDED:
- Professional responsive homepage and tool directory
- Separate About, Contact, FAQ, Privacy, Terms, Disclaimer and Advertise pages
- Merge PDF, Split PDF, Rotate PDF, JPG/PNG to PDF, DOCX to PDF, Extract Pages, PDF Info and basic re-save tools
- Donation contact number 76740 97096
- Like and Share controls
- Ad placement placeholders
- robots.txt, sitemap.xml and CNAME

ADS:
Ad spaces are placeholders. They do not display ads automatically. Apply to an ad provider such as Google AdSense and wait for approval. Then insert the exact code and publisher/ad-slot IDs supplied by the provider. Do not make up IDs. Add legally required consent and privacy notices before activating advertising.

DONATION:
The website displays 76740 97096 as a donation contact number. It does not claim this number is a verified UPI ID. Confirm the exact UPI ID before creating a payment link or QR code.

LIMITATIONS:
No PDF encryption/password protection, OCR, e-signature or guaranteed compression. Word conversion can alter complex formatting. PDF libraries are loaded from public CDNs, so a working internet connection is required. Test the website on mobile and desktop before promoting it.
